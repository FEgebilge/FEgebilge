🔗 **Integration Mindset -** Working across enterprise systems and teams has strengthened my understanding of how technical and business components interact.

🔧 **Learning DevOps -** Continuously improving my understanding of CI/CD pipelines, version control workflows, and the broader delivery lifecycle of software systems.

## 🏢 What I Do at Work

I'm currently learning a lot in an enterprise environment and honestly, it's been a great crash course in how real-world software gets built.

Being the bridge between **business units and technical solutions**:

- 💬 **Collaborating with stakeholders** to understand real needs behind requirements  
- 🧩 **Designing solution architectures** aligned with existing systems, policies and long-term goals  
- 🔗 **Building integrations** across platforms and data sources  
- 🛠️ **Developing solutions** from custom applications to Power Platform-based tools  
- 🔄 **Iterating and improving**, because v1 is never truly finished  

What I value most is choosing the **right tool for the problem:** low-code when it fits, custom code when it doesn’t. Approaching solutions with an awareness that delivery is about systems, people and processes working together.
